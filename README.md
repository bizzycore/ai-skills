# AI Skills

Private source of truth for Chris Carpenter's reusable AI workflows. Each folder is a self-contained Codex skill with durable instructions only; sensitive case data, credentials, transcripts, and workspace contents do not belong here.

## Skills

- `job-search`: application packages and live interview materials
- `writing-voice`: writing and editing in Chris's natural voice
- `resale`: efficient resale research and listing workflows
- `benefits-hra`: benefits, HRA, and unemployment guidance
- `openclaw`: safe OpenClaw operations and troubleshooting
- `mac-troubleshooting`: narrow, approval-aware Mac diagnostics

Codex discovers installed copies from `~/.codex/skills/<skill-name>/SKILL.md`. ChatGPT can use this private repository when its GitHub connection is granted repository access.
